# ============================================================
# 传感器回放文件示例 —— 供 config 里 sensors[].backend: file 使用
# ------------------------------------------------------------
# 用法(在 config/config.test.yaml 里改):
#   sensors:
#     - kind: infrared
#       name: ir_1
#       backend: file
#       path: scripts/sensor_replay_demo.txt
#       rate_hz: 10
#       labels: ["person"]
#
# 行格式: [timestamp_ms,]label,confidence[,distance_m[,x,y,w,h]]
#   * 首列是整数 => 视为**源文件内的相对时间戳**, 决定行与行之间的播放间隔
#     (本文件 100ms/行 => 10Hz; 播放时按此间隔限速, 不要用真实时钟的大数值);
#   * 省略 x,y,w,h => 该模态"不提供像素框"(雷达点) -> 融合走"标签关联"分支;
#   * 提供 x,y,w,h  => 融合走"IoU 关联"分支(需 >= fusion.match_iou);
#   * 以 '#' 开头的行为注释, 空行忽略;
#   * labels 白名单在 config 里配, 不在此文件中表达。
#
# 注意: 这里给的框坐标是**按 720x1280 竖屏假设**的示例。要让 IoU 关联命中,
#       请把 x,y,w,h 改成与 output.avi 里 person 框大致重叠的值(或在
#       db_fallback.csv 的检测记录里查真实框)。若只想看到 matched>0,
#       用 backend: stub 的雷达(无框 -> 标签关联)最省事。
# ============================================================
